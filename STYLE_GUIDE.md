# Style Guide — Kitman Labs Design Prototyping Kit

A shared reference for building prototypes in this kit. Everything below is pulled from the live repo (`src/styles/design-tokens.css`, `DESIGN_SYSTEM.md`, `PROJECT_STANDARDS.md`, and the component source). This is a **design system reference implementation** — matching token and component usage is the primary quality bar, and lint/pre-commit hooks enforce most of it automatically.

---

## 1. Colors

All colors are CSS custom properties in `src/styles/design-tokens.css`. **Never hardcode hex/rgb/hsl** — linting blocks the commit. Reference as `var(--color-*)`.

### Brand
| Token | Hex | Use |
|---|---|---|
| `--color-primary` | `#3B4960` | Primary brand (Medinah navy), buttons, active nav |
| `--color-primary-hover` | `#2f3a4d` | Primary hover |
| `--color-primary-light` | `#f2f3f5` | Tinted backgrounds |
| `--color-primary-dark` | `#232b3a` | Deep accents |
| `--color-secondary` | `#F1F2F3` | Secondary buttons, subtle fills |
| `--color-ai-purple` | `#3c3489` | AI summary / generation states |

### Domain-specific
- **Medical:** `--color-medical-critical/warning/healthy/recovery`
- **Availability:** `--color-available #28a745`, `--color-unavailable #dc3545`, `--color-limited #ffc107`, `--color-unknown #6c757d`
- **Performance:** `--color-performance-excellent/good/average/poor`
- **Charts:** `--color-chart-1` … `--color-chart-10` (starts `#3B4960`, `#29AE61`, `#F1C410`, `#C0392B`, `#9b58b5`…)
- **Calendar / screenshot-aligned:** iOS-style accents — `--color-calendar-accent #007AFF`, `--color-sidebar-bg #2C2C2E`, event blue/red/purple.

### Borders & backgrounds
`--color-border-primary #e0e0e0`, `--color-border-secondary #f0f0f0`, `--color-border-focus #3B4960`; backgrounds `--color-background-primary #ffffff`, `-secondary #f8f9fa`, `-tertiary #f0f0f0`, overlay `rgba(0,0,0,0.5)`.

## 2. Typography

- **Primary font:** `Open Sans` (loaded via Google Fonts in `index.html`). `Inter` and `Material Icons Outlined` also loaded.
- **Mono:** `Roboto Mono`.
- **Sizes:** `--font-size-xs 12` · `sm 14` · `base 16` · `lg 18` · `xl 20` · `2xl 24` · `3xl 30` · `4xl 36` (px).
- **Weights:** light 300 · normal 400 · medium 500 · semibold 600 · bold 700 · extrabold 800.
- **Line heights:** tight 1.2 · normal 1.5 · relaxed 1.8.
- **Text casing:** **sentence case everywhere** — "Add athlete", not "Add Athlete" or "ADD ATHLETE". Enforced by lint.
- **Placeholders:** unified — Open Sans, 14px, semibold (600), `--color-text-muted`, full opacity. Applied globally in the tokens file.

---

## 3. Spacing, radius, shadows, layout

- **Spacing scale:** `xs 4` · `sm 8` · `md 16` · `lg 24` · `xl 32` · `2xl 48` · `3xl 64` (px).
- **Radius:** `sm 4` · `md 8` · `lg 12` · `xl 16` · `full 50%`.
- **Shadows:** `sm`, `md`, `lg`, `xl` (increasing y-offset/blur), plus `--shadow-dialog` and `--shadow-nav`.
- **Layout:** nav width `240px` (collapsed `60px`), header height `60px`, max content width `1200px`.
- **Z-index scale:** dropdown 1000 → sticky → fixed → modal-backdrop → modal → popover → tooltip 1060.
- **Transitions:** fast `0.15s` · normal `0.3s` · slow `0.5s`, all `ease-out`.

## 4. Components — priority order (CRITICAL)

Always reach for components in this order:

1. **Playbook Components** — `import { … } from '../playbook-components'`
   Button, DataGrid, DataGridPremium, DatePicker, Drawer, Toasts, ConfirmationModal, TabBar, SelectWrapper, Autocomplete, RichTextEditor, FileUploads, and more.
   ⚠️ Edit behavior in `src/playbook-components/`. **Never edit `src/playbook-components-build/`** — it's generated by `npm run strip-flow`.
2. **App components** — `import { … } from '../components'`
   Button, Icon, Card, PlayerAvatar, LogoImage, StatusChip, AthleteDataGrid, LayoutWithMainNav, MainNavigation.
3. **MUI fallback** — `@mui/material` only when 1 and 2 have no equivalent.

### MUI prop defaults (write explicitly, even though the theme enforces them)
| Component | Required props |
|---|---|
| TextField | `variant="filled" size="small"` |
| Button | `variant="contained" size="small" disableElevation={true}` |
| Select / FormControl | `variant="filled" size="small"` |
| Autocomplete | `size="small"` |
| Chip / IconButton | `size="small"` |
| LoadingButton | `variant="contained" size="small" disableElevation={true}` |

### Button styling
Filled only (no `outlined` / `text`). Sentence case, `--radius-sm`, padding `8px 16px`, font-size 14 / weight 500. Primary = navy on white text; secondary = `--color-secondary` on primary text.

### Icons
**Material Icons Outlined only** — e.g. `DashboardOutlined`, never `Dashboard`. Sizes: small 16 · medium 20 · large 24. Enforced by lint.

## 5. Naming & file conventions

- **Mock data / fixtures / form templates** → `src/data/` (never inline in components). Form templates → `src/data/formTemplates/`.
- **Pages / views** → `src/pages/` (e.g. Calendar, Medical, Medications, BodyMap, forms, RolePermissions).
- **App components** → `src/components/`; **shared wrappers** → `src/playbook-components/` (source) — build output is generated.
- **Storybook stories** → `src/stories/`.
- Don't add one-off components at repo root.

---

## 6. Stack & tooling

- **React 18 · Vite 7 · MUI 5 · Emotion.** Router: `react-router-dom` v6. Dates: `date-fns` / `dayjs`. Grids: `@mui/x-data-grid(-pro)`.
- **Dev:** `npm run dev` → `localhost:3001`. **Storybook:** `npm run storybook` → `:6006`.
- **Lint/validate:** `npm run validate-design-system` (runs pre-commit) — colors, button variants, icon variants, text casing.
- **Deploy:** Vercel is already wired up (`.vercel/`, `vercel.json` with SPA rewrite to `/index.html`). Build = `npm run build` → `dist/`.

---

## 7. Do / Don't

✅ Use design tokens for every color · Playbook Components first · sentence case · Outlined icons · put mock data in `src/data`.
🚫 Hardcode colors · use `outlined`/`text` buttons · use non-Outlined icons · edit `playbook-components-build/` · add npm deps without instruction.
